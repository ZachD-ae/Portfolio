# Zach Donels – Developer Portfolio

This is a single-page React application that serves as a professional portfolio for Zach Donels, showcasing his background in front-end development, graphic design, video production, and creative technologies.

Built with React and styled using Bootstrap, the site features dedicated sections for About, Portfolio, Contact, and Resume, along with clean routing and responsive design.

## Features

- Single-page application built with React and Vite
- Responsive layout using Bootstrap 5
- Project showcase grouped by category (Programming, Graphic Design, Visuals & Video)
- Contact form with validation
- Professional UI/UX structure suitable for employers and collaborators

## Technologies Used

- React
- Vite
- Bootstrap 5
- HTML5 & CSS3
- Font Awesome

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/ZachD-ae/Portfolio.git
   cd your-repo-name
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

## Deployment

This application is deployed using [Netlify]([https://www.netlify.com](https://prismatic-strudel-eb6785.netlify.app/)/) and is continuously updated via GitHub.
